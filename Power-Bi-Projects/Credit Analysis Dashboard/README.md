# Credit Analysis Dashboard | Power BI

## 📌 Project Overview

The **Credit Analysis Dashboard** is an interactive Power BI project focused on analyzing customer credit profiles, credit risk categories, and loan approval and rejection patterns.

The dashboard is organized into three pages, providing an overview of the credit portfolio, customer credit risk, and loan approval and rejection rates through KPI cards, charts, a map, and interactive slicers.

## 🎯 Project Objectives

- Analyze key credit portfolio metrics.
- Explore customer credit risk categories and credit scores.
- Examine loan approval and rejection patterns.
- Compare credit and loan-related measures across customer segments.
- Present the analysis through an interactive Power BI dashboard.

## 📊 Dashboard Pages

### 1. Credit Portfolio Overview

This page provides an overview of the credit portfolio through key performance indicators and customer and loan-related comparisons.

**Key Performance Indicators (KPIs)**

- Total Customers
- Total Loan Amount
- Approved Loans
- Rejected Loans
- Average Interest Rate

**Visualizations and Analysis**

- Loan distribution by loan type
- Customer analysis by state
- Customer analysis by education
- Customer analysis by employment type

**Interactive Filters**

- Gender
- State
- Loan Type

### 2. Customer Credit Risk Analysis

This page focuses on customer credit profiles and the distribution of customers across credit risk categories.

**Key Performance Indicators (KPIs)**

- Average Credit Score
- Average Loan Amount
- High-Risk Customers
- Low-Risk Customers

**Visualizations and Analysis**

- Customer distribution by risk category
- Credit score analysis by loan type
- Credit score analysis by employment type
- State-wise credit score analysis using a map
- Customer analysis by education
- Customer analysis by gender
- Customer analysis by employment type
- Customer analysis by state

### 3. Loan Approval & Rejection Rate

This page presents loan approval and rejection metrics and comparisons across customer segments.

**Key Performance Indicators (KPIs)**

- Loan Approval Rate
- Loan Rejection Rate
- Approved Loan Count
- Rejected Loan Count

**Visualizations and Analysis**

- Loan amount analysis by loan status
- Loan approval rate comparison by gender
- Loan rejection rate comparison by gender
- Loan approval and rejection analysis by state

**Interactive Filters**

- Gender
- Employment Type
- State
- Loan Type

## 🛠️ Tools Used

- **Microsoft Power BI** — Dashboard development, KPI presentation, data visualization, and interactive analysis.

## ✨ Dashboard Features

- Three dedicated pages for credit portfolio, customer credit risk, and loan approval and rejection analysis.
- KPI cards for presenting important credit and loan metrics.
- Charts for comparing customer groups and loan-related measures.
- Map visualization for state-wise credit score analysis.
- Interactive slicers for exploring the available data by category.
- A consistent dashboard theme across the report.

## 🎯 Project Scope

This project focuses on presenting credit-related metrics and exploring customer credit risk and loan approval patterns through Power BI visualizations.

The README documents the dashboard structure and reported features. It does not claim additional tools, transformations, forecasting, or analytical results that have not been verified.
